# DropSound

TVTestでドロップしたらサウンドを鳴らすプラグインです。

## 導入

[Releases](../../releases) から zip をダウンロードし、使っている TVTest に合わせてどちらか一方を TVTest の `Plugins` フォルダにコピーします。

| TVTest | ファイル |
| --- | --- |
| 32bit | `bin\x86\DropSound.tvtp` |
| 64bit | `bin\x64\DropSound.tvtp` |

TVTestを起動し、メニューの「プラグイン」から「DropSound」を有効にします。

## 設定

「プラグイン」の設定画面から DropSound を選び、「設定」を押します。

- **システム音**: Windows のサウンド(警告、システムエラー、通知など)から選びます。
- **音声ファイル**: WAV / MP3 / WMA などのファイルを指定します。
  ファイルを開けない場合は、代わりに警告音が鳴り、TVTest のログにエラーが記録されます。
- **音量**: 0〜100% で設定できます。
- **鳴らすタイミング**
  - **Drop の数値が増えるたびに毎回鳴らす**: 0.5 秒ごとの確認でドロップ数が増えていれば、毎回鳴らします。
  - **間隔を空けて鳴らす**: ドロップが続いても、指定した秒数に最大 1 回だけ鳴らします(初期値 2 秒)。
  - どちらの場合も、前の音が鳴り終わる前に次の音を鳴らすときは、止めずに重ねて鳴らします(同時に 8 つまで)。
  - **映像・音声の PID でドロップしたときだけ鳴らす**: 視聴中のサービスの映像と音声の PID でドロップしたときだけ鳴らします。
    データ放送や EPG など、それ以外の PID のドロップでは鳴りません。
    この設定では TS パケットの連続性カウンタをプラグイン自身が調べてドロップを数えるため、
    TVTest に表示されるドロップ数とは一致しないことがあります(ピッチの判定にもこの数を使います)。
- **ピッチ**: 「増加量が多いほどピッチを上げる」をオンにすると、ドロップの増え方に応じて音が高くなります。
  増加量は 1 秒あたりに換算して判定します(例: 0.5 秒で 50 増えた場合は、1 秒あたり 100 として扱います)。
  再生速度を上げて音を高くするので、高くなるほど音は短くなります。

  | 1 秒あたりの増加量(しきい値 100 の場合) | 上がる量 | 再生速度 |
  | --- | --- | --- |
  | 100 未満 | そのまま | 1.0 倍 |
  | 100 | 2 半音 | 約 1.12 倍 |
  | 1,000 | 6 半音 | 約 1.41 倍 |
  | 10,000 | 10 半音 | 約 1.78 倍 |
  | 31,623 以上 | 12 半音(1 オクターブ、上限) | 2.0 倍 |

- **テスト再生**: 今の設定で音を鳴らします。右の「増加量」に数値を入れると、1 秒あたりその数だけドロップが増えたときの高さで鳴ります。

設定はプラグインと同じフォルダの `DropSound.ini` に保存されます。

## 動作

- ドロップ数を 0.5 秒ごとに確認し、増えていたら音を鳴らします。
- 「映像・音声の PID でドロップしたときだけ鳴らす」がオンのときは、受信した TS パケットを 1 つずつ確認します。
  対象の PID かどうかと連続性カウンタを見るだけなので、負荷はほとんどありません。
- チャンネル、サービス、ドライバの変更時や、ステータスのリセット時はカウントを取り直します。そのため、これらの操作だけで音が鳴ることはありません。
- 対象はドロップのみです。エラーとスクランブルでは鳴りません。

## ビルド

Visual Studio(C++ デスクトップ開発)が入った環境で `build.bat` を実行すると、x86 と x64 の両方がビルドされます。
